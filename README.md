# Кототека

Статическая демка Mewgenics для mewgenics.website.

В репозитории только файлы сайта: интерфейс, снимок котов, иконки и портреты.
Исходный сейв и остальной рабочий проект не включены.
Заметки сохраняются только в браузере; для переноса доступны экспорт и импорт.

Портреты — приближённая реконструкция из ресурсов игры; графика принадлежит её правообладателям.
Неофициальный фанатский инструмент.
